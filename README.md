# Canvas Ball Animation

A simple and visually pleasing canvas animation that renders bouncing balls using vanilla HTML, CSS and JavaScript.

![Canvas Ball Animation Screenshot](./Screenshot%202024-08-15%20123751.png)

## Demo / Preview
Open `index.html` in your browser to see the animation. For the best experience, open it in a modern browser (Chrome, Firefox, Edge, Safari).

## Features
- Animated bouncing balls rendered on an HTML5 <canvas>
- Adjustable canvas that fills the viewport
- Lightweight implementation with plain JavaScript (no libraries)

## Files
- `index.html` — markup and canvas container
- `style.css` — basic styles for layout
- `script.js` — animation logic and ball physics
- `Screenshot 2024-08-15 123751.png` — preview image used above
- `Screenshot 2024-08-15 123816.png`, `Screenshot 2024-08-15 123839.png` — additional screenshots

## How to run
1. Clone the repository:

   git clone https://github.com/BinaryVortex/Canvas-Ball-Animation.git
2. Open `index.html` in your browser. Alternatively, run a simple local server and navigate to http://localhost:8000

   - Using Python 3: `python -m http.server 8000`

## Customize
Open `script.js` to tweak ball count, sizes, colors, and physics parameters (gravity, friction, etc.).
